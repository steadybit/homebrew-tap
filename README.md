# Steadybit Homebrew tap

Homebrew casks for Steadybit tools, on macOS and Linux.

```sh
brew install steadybit/tap/steadybit
```

installs the [Steadybit CLI](https://github.com/steadybit/cli), with its bash, zsh and fish completions. `brew upgrade steadybit` updates it.

The casks here are written by the release workflows of their projects; changes belong in those projects, not in this repository.
